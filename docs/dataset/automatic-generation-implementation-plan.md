# 测评集自动生成开发计划

状态：基础流程已完成，完整能力待补充。

设计依据：

1. `docs/requirements-baseline-zh.md`
2. `docs/architecture-review-ledger.md`
3. `docs/dataset/automatic-generation-plan.md`

## 1. 目标

根据指定版本的 Agent 或 Skill 能力信息，自动生成 AgentGate 测评用例：

```text
选择 Agent/Skill
→ 配置生成数量和类型
→ 大模型生成候选场景
→ 后端转换、校验
→ 用户审核和修改
→ 加入测评集草稿
→ 用户发布新版本
```

大模型只负责提出场景，后端负责数据格式、期望转换、校验、ID、版本和保存。

## 2. 当前已经完成

| 能力 | 当前情况 |
| --- | --- |
| 选择评测对象 | 支持选择 Fake Agent 或 Fake Skill 及其具体版本 |
| 生成配置 | 支持数量、分类、难度、单轮、多轮、混合轮次 |
| 参考用例 | 可选择已发布测评集中的用例作为参考 |
| 大模型调用 | 已接入百炼 OpenAI-compatible API |
| 结构化生成 | 模型只生成简化 Blueprint，不直接生成复杂 Case |
| 输入生成 | 支持生成符合 `input_schema` 的非空输入 |
| Skill 期望 | 支持生成 `expected_skill` |
| 工具期望 | 支持必调工具、禁调工具和工具参数 |
| 输出期望 | 支持输出关键词和 `output_schema` 校验 |
| 多轮用例 | 支持连续多轮输入和逐轮期望 |
| 生成计划约束 | Schema、编辑复验和接收复验均绑定同一签名槽位 |
| 后端校验 | 校验 Skill、工具、参数、Schema、冲突和重复用例 |
| 人工审核 | 支持查看、编辑、重新校验和选择候选用例 |
| 写入草稿 | 选择后的用例原子写入当前测评集草稿 |
| 来源追踪 | 保存 Target、模型和 Prompt Recipe 版本信息 |
| 前端页面 | 已提供“AI 生成测评用例”完整操作入口 |

当前 Recipe：`dataset-case-generation/v14`。

## 3. 当前还未完成

| 优先级 | 未完成能力 | 原因或需要补充的内容 |
| --- | --- | --- |
| P0 | 接入真实 Agent/Skill | 当前使用 Fake Catalog，需要外部平台提供只读对象和版本接口 |
| P0 | 状态期望生成 | Target 需要提供 `state_schema` 或可用状态字段 |
| P0 | 规则期望生成 | Target 需要提供带稳定 ID 的规则目录 |
| P0 | 生成失败自动修复 | 当前一批只调用一次模型，需要针对失败用例进行一次有限修复 |
| P1 | 初始状态生成 | 需要声明哪些字段允许写入 `initial_state` |
| P1 | 工具调用顺序 | 当前只能判断必调、禁调，不能表达完整调用轨迹 |
| P1 | 生成质量报告 | 需要展示 Skill、工具、分类和边界场景的覆盖情况 |
| P1 | 候选持久化 | 当前刷新页面会丢失尚未接收的候选 |
| P1 | 语义去重 | 当前只有确定性精确去重 |
| P1 | 生产级密钥管理 | API Key 当前只保存在后端进程内存中 |
| P1 | 完整敏感信息脱敏 | 当前以密钥和 Token 脱敏为主 |
| P2 | 从失败结果生成用例 | 需要关联具体 Run、Result 和原测评集版本 |

## 4. 下一步开发顺序

1. 对接一个真实外部 Agent 和一个真实 Skill，获取完整能力描述。
2. 使用固定真实场景重复测试模型生成质量。
3. 增加失败用例的一次有限修复，保留原始错误。
4. 补充 `state_schema` 和规则目录，再生成状态与规则期望。
5. 增加生成覆盖率报告和候选持久化。
6. 最后完善生产级密钥、脱敏和异步任务。

## 5. 下一阶段验收标准

- 能选择非 Fake 的 Agent 和 Skill，并固定具体版本。
- 生成用例的输入符合 Target Schema。
- 不生成 Target 未声明的 Skill、工具、参数、状态或规则。
- Skill 与工具声明保持一致。
- 有效候选不会因为其他候选失败而丢失。
- 无效候选最多自动修复一次，仍失败则交给用户处理。
- 用户审核确认后才写入草稿，不自动发布。
- 生成用例可正常发布并用于 Run。

## 7. 完成标准

满足以下条件后，可认为测评集自动生成完整可用：

- 已接入真实 Agent/Skill；
- 能生成 AgentGate 支持的各种期望；
- 模型偶发错误能够被校验和有限修复；
- 候选及审核记录可追溯；
- 生成的用例能够发布并进入真实评测流程；
- 全量后端、前端和端到端测试通过。
