# P1 Demo History

These files describe the implemented `goal/p1-demo` baseline and the decisions that led
to it. They are retained for behavior comparison during refactor-1.

Names such as `control_plane/`, `case/`, `RunSnapshot`, and old server paths describe the
historical implementation. They must not be used as the current architecture.

Current authority is `docs/architecture.md` and `docs/refactor-implementation-plan.md`.
