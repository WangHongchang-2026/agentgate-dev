# Documentation History

This directory contains superseded planning and implementation records. Historical
files preserve the reasoning and behavior of earlier stages, but their package paths,
module ownership, and implementation status are not authoritative.

Use the current documents in the parent `docs/` directory for active requirements,
architecture, implementation order, and verified baseline status.

- `p1-demo/`: records for the implemented `goal/p1-demo` baseline.
- `planning-v1/`: design plans written before the refactor-1 architecture was finalized.
